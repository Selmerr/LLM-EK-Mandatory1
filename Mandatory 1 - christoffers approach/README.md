# LLM EK Mandatory 1 - Christoffer's Approach

This project implements the second candidate toolchain for the
Local Multi-LLM Coding Workflow Evaluation.

The approach uses Open WebUI as the user interface and control layer,
with local Ollama endpoints providing the LLM backends.

The workflow will support:

- Architecture
- Technical planning
- Implementation
- Testing and quality
- Documentation
- Deployment validation
